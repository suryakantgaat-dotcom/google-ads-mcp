# Product profile — interview template

Use this when a product has no profile yet. Ask the owner; don't fill answers from inference. Save as `references/profiles/<product>.md` in the same shape as `trackofield.md`.

1. **Account:** account_name, customer_id, currency.
2. **Product definition:** What does the product do, and for whom? What makes a query relevant vs irrelevant? Ask for 3 relevant and 3 irrelevant example queries.
3. **Campaign mapping:** Which campaigns belong to this product line? Which is the brand campaign? Which is the competitor campaign (if any)?
4. **Own brand:** Brand name and the spellings/spacings users type. (Single word → broad; multi-word → phrase, per R5.)
5. **Competitors:** Brands the owner treats as competitors (plus any brand in the competitor campaign's keywords).
6. **Known unrelated brands:** Third-party brands to block everywhere.
7. **Irrelevant modifiers:** Words that make a query off-topic for this product.
8. **Vague terms:** Head terms too broad to convert on their own.
9. **Words that must never be negated** (they appear in core keywords).
